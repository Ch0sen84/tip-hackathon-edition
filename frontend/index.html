    About / Beyond the Hackathon

    TIP (Trading Intelligence Platform) is a signal-detection app built on the Unusual Whales API. This Hackathon Edition is a standalone, public, downloadable build of it -- its gate/confidence/state-transition logic (backend/app/core/signal_engine.py) is ported/equivalent to the production app's logic, run the same way in both demo mode (synthetic fixtures, clearly marked synthetic: true) and live mode (your own real Unusual Whales API key). Every NEW / BUILDING / CONFIRMED / STABLE / FADING / INVALIDATED label shown is computed from whatever data the active adapter actually returned -- never a canned conclusion.

    Production TIP is a separate, continuously-running home-lab deployment with infrastructure this build doesn't include by design (futures/market-data collectors, a multi-week scanning history, scheduled reporting, and home-lab automation) -- this build is intentionally scoped to the UW-API-driven Market Radar / Ticker Analysis / Investigate-with-AI workflow only, and does not claim identical real-world coverage.

    This is a public, open-source project -- see the GitHub repository for source, issues, and participation.
