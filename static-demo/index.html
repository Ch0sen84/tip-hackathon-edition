    About / Beyond the Hackathon

    TIP (Trading Intelligence Platform) is a signal-detection app built on the Unusual Whales API. This page is the public, static demo of its Hackathon Edition -- credential-free, backend-free, and limited to pre-captured simulated output. The downloadable local edition runs the exact same shared rendering code (app.core.js) against a real backend, in either synthetic demo mode or real-API live mode. Every NEW / BUILDING / CONFIRMED / STABLE / FADING / INVALIDATED label on this page is computed from the pre-captured simulated data, never a canned conclusion.

    Production TIP is a separate, continuously-running home-lab deployment with infrastructure this build doesn't include by design (futures/market-data collectors, a multi-week scanning history, scheduled reporting, and home-lab automation) -- this build's logic is ported/equivalent to production's, not claimed identical.

    This is a public, open-source project -- see the GitHub repository for source, issues, and participation.
