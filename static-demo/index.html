About / Beyond the Hackathon

This is a standalone hackathon build of TIP (Trading Intelligence Platform). The gate / confidence / state-transition logic in backend/app/core/signal_engine.py is ported verbatim from the production app and runs identically whether the backend is in demo mode (synthetic fixtures, clearly marked synthetic: true) or live mode (real Unusual Whales API). Nothing shown here is a canned conclusion -- every NEW / BUILDING / CONFIRMED / STABLE / FADING / INVALIDATED label is computed from whatever data the active adapter returned.

Beyond this hackathon build, the full production TIP platform additionally includes: Databento/futures collectors, a production TimescaleDB history spanning weeks of continuous scanning, scheduled Discord reporting, an experimental Research Lab, and home-lab infrastructure automation. None of that is included here by design -- this public demo is credential-free, static, and limited to pre-captured simulated output.
